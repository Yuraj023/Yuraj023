## 🚀 Featured Projects

### 🤖 AI Complaint Categorizer
A machine-learning system for automatically categorizing citizen complaints using a logistic-regression-based classification approach, with an accompanying dashboard for interacting with and analyzing the results.

### 📚 RAG Chatbot
A document-based conversational AI system that uses Retrieval-Augmented Generation (RAG) to turn static documents into an interactive conversational interface.

### 🌱 ESP32 Air Quality Monitor
An IoT project using ESP32 and sensors to collect air-quality data and stream it to a real-time dashboard.

### 🧠 Character-Level LSTM
A character-level language model built from scratch using NumPy, implemented to understand the internal mechanics of LSTMs, including gate calculations, cell-state updates, hidden states, and Backpropagation Through Time.
